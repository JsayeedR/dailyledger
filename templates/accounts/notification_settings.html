How to create a Telegram Bot

  1. Open Telegram and search for @BotFather
  2. Send /newbot and follow the prompts (choose a name and a username ending in "bot")
  3. BotFather replies with a token like 123456789:ABCdefGhIJKlmNoPQRstuVwxyZ
  4. Copy that token and paste it below

Each user must message your bot at least once (e.g. send /start) — Telegram only lets a bot message people who've messaged it first. They should also set their Chat ID in their Profile page.
